# Auto Captions in Bulgarian

Приложението позволява качване на аудио или видео файл и създава автоматични надписи на български.

## Изисквания
- Python 3
- Flask
- [Whisper](https://github.com/openai/whisper)

Инсталирайте зависимостите:
```bash
pip install -r requirements.txt
```

Стартирайте приложението:
```bash
python app.py
```

Отворете браузър на `http://localhost:5000` и качете файл за транскрипция.
